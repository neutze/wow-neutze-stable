# CurseForge page: Neutze's Stable
**Name:** Neutze's Stable
**Summary:** Set one mount per character and get a mount macro that mounts it or dismounts you.
**Categories:** Collections (main), Action Bars
**License:** MIT · **Source:** https://github.com/neutze/wow-neutze-stable · **Logo:** art/logo-400.png

## Description
Type the mount for this character (`/stable Swift Palomino` or Options > AddOns > Neutze's Pantry > Neutze's Stable). It writes a character macro **NPstMount** that mounts that mount, or dismounts you if you're mounted.

- "Use current mount" takes the mount you're sitting on.
- Partial names work; change the name and the macro updates.
- Macro changes wait until combat ends.
- Requires **Neutze's Pantry** (set it as a required dependency on CurseForge). The field also appears in `/np`.
